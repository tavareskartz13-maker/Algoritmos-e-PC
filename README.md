## Objetivo do repositório

Reunir as atividades práticas desenvolvidas ao longo do semestre na disciplina, todas implementadas em linguagem C, organizadas por aula, lista de exercícios e projetos.

## Organização das pastas

```
Algoritmos-e-PC/
├── README.md
└── Aula10/
    └── Exercicio01/
        ├── README.md
        └── consumo_energia.c
```

Cada aula possui uma pasta (`AulaXX`), e dentro dela uma pasta para cada exercício (`ExercicioXX`) ou projeto (`ProjetoXX`). Cada atividade tem seu próprio `README.md` com enunciado, objetivo, descrição da solução e observações.

## Como compilar e executar

É necessário ter o compilador GCC instalado. Dentro da pasta da atividade:

```bash
gcc -Wall -o programa arquivo.c
./programa
```

No Windows, o executável gerado pode ser rodado com `programa.exe`.
